# Forecast statistics

The statistics panel scores loaded forecast output against a reference analysis
and tabulates the result by lead time. It is the quantitative half of the
comparison workflow that the plots handle qualitatively.

## The reference

By default the reference is **GFS analysis** at the forecast's valid times. This
matters for interpretation: you are measuring the distance between an AI model's
forecast and an operational NWP analysis, not against truth. Where the analysis
itself is poorly constrained — data-sparse regions, boundary layer detail — the
scores inherit that uncertainty.

Verification requires that forecast and reference be on a common grid and at
matched valid times. Mismatched grids are interpolated; mismatched valid times
are dropped rather than nearest-neighboured, so a partial overlap yields a
partial score table rather than a silently wrong one.

## Metrics

### RMSE

Root-mean-square error, computed per lead time over the selected domain:

$$
\mathrm{RMSE}(\tau) = \sqrt{ \frac{\sum_i w_i \left( f_i(\tau) - a_i(\tau) \right)^2}{\sum_i w_i} }
$$

where $f$ is the forecast, $a$ the analysis, $\tau$ the lead time, and $w_i$ a
latitude weight ($\cos\phi$) so that the dense polar grid points do not dominate
a global average.

Available for deterministic and ensemble-mean output.

### CRPS

Continuous Ranked Probability Score, for ensemble output only. CRPS generalizes
absolute error to a predictive distribution:

$$
\mathrm{CRPS} = \int_{-\infty}^{\infty} \left( F(x) - \mathbb{1}\{x \ge a\} \right)^2 \, dx
$$

with $F$ the ensemble CDF and $a$ the observed (analysis) value. Lower is better,
and it reduces to absolute error for a single-member "ensemble" — which is why
you cannot compare a deterministic CRPS against an ensemble CRPS and draw a
conclusion about skill.

### Spread/error ratio

The ratio of ensemble spread to ensemble-mean RMSE, per lead time. This is a
calibration diagnostic, not a skill score:

- **≈ 1** — the ensemble's spread is a reasonable estimate of its own error.
  Well calibrated.
- **< 1** — underdispersive. The ensemble is more confident than it is accurate;
  a common failure mode for AI ensembles generated by perturbing initial
  conditions alone.
- **> 1** — overdispersive. The spread is wider than the error.

Read it alongside CRPS. An underdispersive ensemble can still have a good CRPS,
and reporting one without the other overstates the result.

## Reading the table

Scores are reported per lead time for the currently selected variable, so the
sidebar controls determine what is being scored. Switching variables recomputes.

Comparing models fairly requires that all of them were run from the **same
initialization time** to the **same lead time** — which is why the sidebar shares
those controls across the models you select. If you load output from separate
sessions with different initializations, the table will still compute, and the
comparison will be meaningless.

## Caveats worth stating in a paper

1. Scores against an analysis are not scores against observations.
2. AI models trained on ERA5 and verified against GFS analysis carry a systematic
   analysis-difference penalty that an ERA5-verified score would not show.
3. Latitude weighting choices change global RMSE materially; state yours.
4. A single case is a case study. Skill claims need a sample of initializations.

InferStudio is built for the screening step — finding the cases and models worth
investigating properly. It is not a substitute for a scorecard produced over a
proper verification period.
